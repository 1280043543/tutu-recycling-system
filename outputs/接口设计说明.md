# 接口设计说明

## 1. 接口约定

- API 前缀为 `/api`，使用 REST 风格和 JSON，字符集 UTF-8。
- 登录后携带身份凭证，服务端校验身份、角色、资源归属和订单状态。
- 列表接口分页，默认 `pageNum=1`、`pageSize=10`。
- 字段名和状态编码使用英文；页面将状态码映射为中文。
- 订单状态由服务端业务逻辑控制，客户端不提交任意目标状态。

统一响应：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {}
}
```

分页数据：

```json
{
  "records": [],
  "total": 0,
  "pageNum": 1,
  "pageSize": 10
}
```

## 2. 账号接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| POST | `/api/auth/register` | 未登录 | 居民注册，不含手机验证码 |
| POST | `/api/auth/login` | 未登录 | 用户登录 |
| POST | `/api/auth/logout` | 已登录 | 用户退出 |
| GET | `/api/users/me` | 已登录 | 查询本人资料 |
| PUT | `/api/users/me` | 已登录 | 修改本人可维护资料 |
| PUT | `/api/users/me/password` | 已登录 | 修改密码 |

注册请求示例：

```json
{
  "username": "resident001",
  "password": "用户输入的密码",
  "realName": "居民姓名",
  "phone": "13800000000"
}
```

密码只能安全存储，接口响应不得返回密码。

## 3. 地址与品类接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| GET | `/api/addresses` | 居民 | 查询本人地址 |
| POST | `/api/addresses` | 居民 | 新增地址 |
| GET | `/api/addresses/{id}` | 地址所属居民 | 查询地址详情 |
| PUT | `/api/addresses/{id}` | 地址所属居民 | 修改地址 |
| DELETE | `/api/addresses/{id}` | 地址所属居民 | 逻辑删除地址 |
| PUT | `/api/addresses/{id}/default` | 地址所属居民 | 设置默认地址 |
| GET | `/api/categories` | 已登录用户 | 查询启用品类 |
| GET | `/api/categories/{id}` | 已登录用户 | 查询品类详情 |
| GET | `/api/admin/categories` | 管理员 | 查询全部品类 |
| POST | `/api/admin/categories` | 管理员 | 新增品类 |
| PUT | `/api/admin/categories/{id}` | 管理员 | 修改品类 |
| PATCH | `/api/admin/categories/{id}/status` | 管理员 | 启用或停用品类 |

## 4. 居民订单接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| POST | `/api/orders` | 居民 | 提交回收申请 |
| GET | `/api/orders/mine` | 居民 | 分页查询本人订单 |
| GET | `/api/orders/{id}` | 所属居民或管理员 | 查询订单详情 |
| POST | `/api/orders/{id}/cancel` | 所属居民 | 取消待审核或待分派订单 |
| POST | `/api/orders/{id}/confirm-result` | 所属居民 | 确认回收结果 |
| POST | `/api/orders/{id}/raise-objection` | 所属居民 | 对回收结果提出异议 |
| POST | `/api/orders/{id}/review` | 所属居民 | 评价已完成订单 |

提交申请示例：

```json
{
  "addressId": 12,
  "appointmentTime": "2026-10-20T14:00:00",
  "description": "补充说明",
  "items": [
    {
      "categoryId": 3,
      "estimatedQuantity": 1,
      "itemDescription": "家电状况"
    }
  ]
}
```

居民只能取消 `PENDING_REVIEW` 或 `PENDING_ASSIGNMENT` 状态订单。其他状态由后端拒绝直接取消并提示联系管理员。

## 5. 管理员订单接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| GET | `/api/admin/orders` | 管理员 | 按订单号、居民、人员、状态和时间筛选 |
| GET | `/api/admin/orders/{id}` | 管理员 | 查看订单详情和操作记录 |
| POST | `/api/admin/orders/{id}/approve` | 管理员 | 审核通过 |
| POST | `/api/admin/orders/{id}/reject` | 管理员 | 驳回并说明原因 |
| POST | `/api/admin/orders/{id}/assign` | 管理员 | 分派回收人员 |
| POST | `/api/admin/orders/{id}/reassign` | 管理员 | 重新分派 |
| POST | `/api/admin/orders/{id}/handle-cancellation` | 管理员 | 处理已分派后的取消请求 |
| POST | `/api/admin/orders/{id}/handle-exception` | 管理员 | 处理订单异常 |

分派请求示例：

```json
{
  "workerId": 25,
  "comment": "分派说明"
}
```

## 6. 回收人员任务接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| GET | `/api/worker/tasks` | 回收人员 | 查询本人任务 |
| GET | `/api/worker/tasks/{orderId}` | 该任务回收人员 | 查询任务详情 |
| POST | `/api/worker/tasks/{orderId}/accept` | 该任务回收人员 | 确认接单 |
| POST | `/api/worker/tasks/{orderId}/reject` | 该任务回收人员 | 拒绝并填写原因 |
| POST | `/api/worker/tasks/{orderId}/start` | 该任务回收人员 | 更新为回收中 |
| POST | `/api/worker/tasks/{orderId}/result` | 该任务回收人员 | 登记实际结果 |
| POST | `/api/worker/tasks/{orderId}/exception` | 该任务回收人员 | 提交执行异常 |

结果登记请求示例：

```json
{
  "remark": "回收备注",
  "items": [
    {
      "categoryId": 3,
      "actualQuantity": 1,
      "actualWeight": 42.50,
      "weightUnit": "kg"
    }
  ]
}
```

结果按品类登记数量和重量，不接收金额字段。成功后订单进入 `PENDING_RESIDENT_CONFIRMATION`。

## 7. 用户和统计接口

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| GET | `/api/admin/users` | 管理员 | 按角色、账号、姓名和状态查询用户 |
| POST | `/api/admin/workers` | 管理员 | 创建回收人员账号 |
| GET | `/api/admin/users/{id}` | 管理员 | 查询用户资料 |
| PATCH | `/api/admin/users/{id}/status` | 管理员 | 启用或停用账号 |
| GET | `/api/admin/statistics/overview` | 管理员 | 订单总量和状态分布 |
| GET | `/api/admin/statistics/categories` | 管理员 | 按品类统计实际回收数量 |
| GET | `/api/admin/statistics/weight` | 管理员 | 实际重量统计 |

统计接口可按时间范围筛选，不统计金额。

## 8. 错误处理

| 情况 | 处理要求 |
|---|---|
| 未登录或凭证过期 | 返回未认证错误 |
| 角色无权限 | 返回无权限错误 |
| 订单不存在或不属于当前用户 | 拒绝访问且不泄露他人数据 |
| 当前状态不允许操作 | 返回状态冲突及说明 |
| 参数缺失或格式错误 | 返回字段校验信息 |
| 用户或品类已停用 | 拒绝相关业务操作并说明原因 |

## 9. 状态展示

例如接口返回 `PENDING_RESIDENT_CONFIRMATION`，前端显示“待居民确认”。英文编码用于程序判断，中文文案用于页面展示。
